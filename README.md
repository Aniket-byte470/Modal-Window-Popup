# 🎉 Modal Magic

**Modal Magic** is a simple and interactive modal window popup, built with HTML, CSS, and JavaScript. This project allows you to display a modal window when clicking a button and close it by clicking a close button or anywhere outside the modal. You can also close the modal with the "Escape" key on the keyboard.

## 🕹️ How to Use

- **Show Modal**:  
  - Click any of the "Show modal" buttons to display the modal window.

- **Close Modal**:  
  - Click the "×" button inside the modal to close it.  
  - Click anywhere outside the modal window (on the overlay) to close it.  
  - Press the "Escape" key on your keyboard to close the modal.

## 🚀 Features

- Interactive modal window that appears with a button click.  
- Modal can be closed with the close button, overlay, or by pressing the "Escape" key.  
- Fully responsive and user-friendly interface with a smooth visual design.

## 🛠️ Technologies Used

- HTML  
- CSS  
- JavaScript
